# 📦 Ejercicio Práctico Integrador — LASIN Python

Este directorio contiene el **Ejercicio Práctico Integrador (LogiFlow)** que reúne las competencias fundamentales desarrolladas durante el curso:

* 📄 [**ENUNCIADO.md**](./ENUNCIADO.md): Especificación detallada de requerimientos, modelado POO, persistencia SQLite, consumo de API, exportación JSON y casos de prueba.
* 📊 [**datos_envios.csv**](./datos_envios.csv): Dataset de prueba con datos limpios, atípicos, duplicados y con errores para probar la resiliencia de tu solución.

### 🚀 Instrucciones para el Estudiante:
1. Lee con detenimiento el archivo [ENUNCIADO.md](./ENUNCIADO.md).
2. Desarrolla tu script (por ejemplo `mi_solucion_integrador.py`) en este directorio.
3. Ejecuta tu solución contra el archivo [datos_envios.csv](./datos_envios.csv) y verifica que el reporte por consola, la base de datos `envios.db` y el archivo `resumen_auditoria.json` coincidan con lo especificado.
